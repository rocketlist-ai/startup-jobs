# RocketList distribution loop

The repository and Agent Skill are acquisition surfaces for RocketList, not just mirrors. The loop is:

1. A job seeker, developer, analyst, or agent discovers the dataset or skill.
2. They install the skill, download a release, or cite an analysis.
3. Every result links to RocketList and the original application.
4. Useful public analyses earn backlinks and agent citations.
5. Search visibility and installs create more users and contributors.

## Priority order

1. **Reliable agent access.** Restore `https://rocketlist.ai/mcp`, keep the GitHub-backed skill as the fallback, and publish copy-paste setup for Claude, Codex, Cursor, VS Code, and ChatGPT where supported.
2. **Canonical open-data page.** Add `rocketlist.ai/open-data` with a plain-language description, current counts, install command, download links, methodology, update timestamp, citation, and links back to this repository. Add `Dataset`/`DataDownload` JSON-LD and include the page in the sitemap.
3. **One coordinated launch.** Launch the dataset and skill together on GitHub, Hacker News, Product Hunt, LinkedIn, X, relevant Reddit communities, and data/AI newsletters. Lead with the usable artifact and a reproducible finding, not a generic product announcement.
4. **Recurring data stories.** Publish a weekly Startup Hiring Index from the current snapshot: fastest-growing categories, locations, stages, investors, remote share, salary coverage, and newly active companies. Each story links to its query or downloadable data.
5. **Syndication and integrations.** Mirror releases on Hugging Face and Kaggle; propose the skill to agent-skill registries and curated lists; provide small examples for notebooks, career tools, newsletters, university career centers, and VC portfolio teams.

## Measure the funnel

Track weekly: repository views and unique visitors, stars, clones, skill installs where the distributor exposes them, release downloads, referring domains, search impressions/clicks to the open-data page, MCP calls and errors, visits from skill result links, and signup/application-assist conversions. Tag owned links with UTMs. Do not use stars or downloads as a substitute for RocketList activation.

## Content rules

- Every number comes from a named snapshot and links to the source or query.
- Publish stable URLs and update existing canonical pages instead of creating near-duplicates.
- Separate facts from interpretation and disclose missing-data coverage.
- Do not mass-post identical copy. Adapt the artifact and explanation to each community.
- Keep application links useful even when the user never signs up.
